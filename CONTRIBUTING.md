# Contributing

Bug fixes, adapter improvements, and new reproducibility checks are welcome.

A vendor may submit a tuned configuration for its own system. The contribution must pin every package, model, prompt, dataset, and configuration value needed to run it. It must state whether the condition is open-source or managed, local or remote, and which reproduction tier it targets.

AX0S will run an accepted vendor configuration on the frozen protocol and publish the result as a new dated condition, whether the result rises or falls. Existing rows remain available with their exact conditions.

Do not submit LoCoMo data, verbatim questions or answers, full receipts, model weights, secrets, hostnames, private paths, or internal network details.
